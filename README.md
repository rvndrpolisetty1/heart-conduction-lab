# Heart Conduction Lab

A concept demo of generative UI for medical teaching. A 3D heart shows how the electrical signal travels, with an ECG in sync, levels for students, and a tutor studio where a lesson builds live.

- **Concept demo:** no AI is called. Every "generated" response is pre-built and labelled as such.
- **Draft for physician review. Not for clinical use.** Synthetic content only. The model is illustrative, not anatomically to scale.

Prototype for The Match Guy. Built by Ravi Polisetti.
