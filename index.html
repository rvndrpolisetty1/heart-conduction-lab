How it works

Lessons that build themselves, checked by a tutor

A tutor asks in plain English. A model of their choice writes the lesson as code, a fixed library of tested components draws it, automated checks test it, and the tutor approves it. Students learn inside it, and can circle anything to get a new panel built for them.

  1. ✎TutorAsks for a lesson
  2. ✦Model of choiceWrites it as code
  3. ◫Component libraryDraws the interactive
  4. ✓AutomatedChecks facts and levels
  5. ◎TutorApproves and publishes
  6. ◯StudentLearns, circles to ask
